# 家庭庫存管理 V12

## 本版變更
- 物品管理清單新增「編輯」按鈕，可修改物品名稱、購買通路、分類、預設存放位置、購買單價、計量單位、低庫存門檻、效期提醒天數及備註。
- 修改物品預設存放位置不會自動修改既有庫存批次的位置；每個批次的位置仍以新增入庫時指定的位置為準。
- 新增入庫的有效期限欄位明確說明：沒有有效期限的商品（如娃娃、包包）可以留空。資料庫的效期提醒只會列出有效期限不為空的批次，因此不會把無效期商品列為過期或即將到期。
- 本版不需要新增資料庫欄位，不需要執行 schema.sql 或任何 migration SQL。

## 更新網站
1. 將 index.html、styles.css、app.js 上傳並覆蓋 GitHub Repository 的同名檔案。
2. 保留 app.js 內既有的 Supabase URL 與 publishable/anon 公開金鑰。
3. 等待 GitHub Pages 部署完成後，以 Ctrl+F5 重新整理。

注意：請勿在前端放置 service_role 或 sb_secret 金鑰。
